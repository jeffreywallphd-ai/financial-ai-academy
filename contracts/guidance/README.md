# Guidance Contracts

Guidance owns safe, versioned product projections that explain how to use the
platform. These records summarize reviewed canonical sources; they do not
replace product, domain, architecture, risk, contract, or method authority.

- [`platform-help/v1/`](platform-help/v1/README.md) defines immutable help
  topics and deterministic browse/search records.
- [`contextual-help/v1/`](contextual-help/v1/README.md) maps one exact feature
  context to ordered exact approved Help topics without moving feature or
  source authority into Guidance or a browser.

Guidance contracts never contain raw markup, executable content, private file
paths, approval or reviewer data, provider payloads, learner-specific advice,
or model-generated authority.
