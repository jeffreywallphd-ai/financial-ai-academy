# Feature Guidance v1 Compatibility Corpus

The approved record and mapping prove exact mapping, canonical digest, closed
action, exact Help reference, publication, and source shapes. Denial cases
exercise unknown or private fields, arbitrary destinations, command and
guarantee language, invalid chronology, and digest drift. The canonicalization
vector fixes the algorithm and expected digests without freezing all valid
wording, action counts, topic counts, registry size, or file order.

Run `python backend/tests/contract/feature_guidance/runner.py` from the
repository root. A consumer is compatible only when both approved artifacts
are admitted and every denial case fails without exposing rejected content or
private paths.
