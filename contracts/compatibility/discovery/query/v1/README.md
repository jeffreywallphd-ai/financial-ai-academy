# Discovery Query v1 Compatibility Corpus

This corpus fixes one normalized deterministic query and result page over the
approved synthetic discovery-v1 lesson. It includes normalization vectors and
bounded schema/semantic denials without personal learner data, provider
payloads, ranking scores, eligibility meaning, or durable cursor state.

The corpus proves portable request/result meaning. It does not by itself
qualify HTTP authorization, generated clients, browser controls, PostgreSQL, or
an external search provider.
