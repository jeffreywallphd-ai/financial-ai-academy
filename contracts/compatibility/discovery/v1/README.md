# Discovery v1 Compatibility Corpus

This corpus fixes one synthetic approved lesson opportunity, its stable browse
generation, deterministic source fingerprint, and bounded denial behavior. It
contains no personal learner data, provider payload, entitlement, ranking
score, or executable lab/project claim.

The approved record uses the exact immutable lesson package introduced by the
Assessment-compatible successor fixture. Contract conformance does not by
itself qualify Curriculum persistence, API authorization, browser behavior, or
any non-lesson destination.
