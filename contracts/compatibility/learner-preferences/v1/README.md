# Learner Preferences v1 Compatibility Corpus

The synthetic corpus fixes one empty profile, one populated explicit profile,
one create-goal intent, bounded non-content change history, and one portable
export. It also fixes fail-closed behavior for private or authoritative fields.

Names and statements are synthetic. The corpus contains no real learner data,
assessment response, inferred trait, recommendation, provider payload,
credential, session, or storage locator.
