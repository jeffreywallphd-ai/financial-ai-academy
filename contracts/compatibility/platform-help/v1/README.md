canonical topic and corpus digests, and bounded denial behavior. It contains no
product help prose, learner data, provider payload, prompt, approval or reviewer
record, private path, executable content, or external instruction.

meaning. It does not qualify the reviewed product corpus, authorization,
persistence, API, generated client, browser, deployment, or live operation.
