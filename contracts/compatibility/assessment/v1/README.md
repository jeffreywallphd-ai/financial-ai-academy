# Assessment v1 Compatibility Corpus

This corpus fixes the positive and negative behavior of the initial
deterministic single-select profile.

- `approved/definition.json` is the private Assessment definition.
- `approved/presentation.json` is the answer-safe learner projection.
- `approved/submissions/` contains correct and incorrect commands.
- `approved/results/` and `approved/events/` contain independently expected
  retained evidence and completion events.
- `cases/denials.json` describes bounded schema and cross-record failures.
- `vectors/` fixes canonical definition and successor-package digests.

The corpus is synthetic educational material. It contains no personal learner
information, provider payload, credential, investment recommendation, or
performance claim.
