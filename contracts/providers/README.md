# Provider Contracts

Provider/plugin manifest, capability, configuration, and family-specific schemas will live here. Provider admission requires conformance, provenance, security, and data-use review.

Identity-provider schemas, when introduced by approved implementation work, must conform to [ADR-0006](../../docs/adr/ADR-0006-setup-selectable-learner-identity.md) and the [identity-provider contract](../../docs/architecture/contracts/identity-provider-contract.md). Do not add placeholder identity schemas before the implementing slice defines exact reviewed shapes.
