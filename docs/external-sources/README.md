# External Source Governance

- Status: accepted
- Canonical for: external source recording and refresh

External laws, regulations, standards, provider terms, data documentation, and model policies can change. Repository summaries do not replace those sources.

For a source-dependent decision, record:

- source title, publisher, and direct URL,
- source type and authority,
- relevant version/effective date,
- repository review date,
- applicability and interpretation,
- affected product, contract, provider, or risk boundary,
- required re-review trigger,
- unresolved uncertainty.

Use `source-register.md` for reviewed sources. Add a specialized refresh workflow before legal-facing, provider-license, interoperability, or external-policy behavior depends on it.
