# Initial Glossary

- Status: proposed
- Canonical for: early shared vocabulary

| Term | Initial meaning |
| --- | --- |
| Learning activity | A versioned unit a learner may undertake and from which evidence may result |
| Competency | A defined capability that can be taught, evidenced, and related to prerequisites |
| Learning evidence | An append-oriented observation such as an attempt, response, score, completion, review, or project artifact |
| Learner state | A versioned projection derived from evidence; not a replacement for the evidence itself |
| Projection override | A time-bounded, learner-visible, append-only overlay on one registered derived learner-state field; it never changes source evidence or the reproducible base projection |
| Adaptive recommendation | A recorded proposal for a next activity after eligibility, ranking, and policy checks |
| Canonical market data | Provider-neutral validated financial data with timestamps, quality flags, and provenance |
| Raw provider data | Untrusted provider-specific input retained only when permitted |
| Simulated portfolio | An educational accounting model that does not represent custody or live trade execution |
| Backtest | A reproducible historical simulation with defined inputs, assumptions, code, and limitations |
| Model execution | A versioned invocation through the platform model gateway with validation and evidence |
| Provider | An implementation of a platform-owned capability contract |
| Durable job | A versioned bounded asynchronous operation delivered at least once with explicit attempts, leases, idempotency or reconciliation, outcome, and failure state |
| Plugin | An independently installable provider or extension admitted through a manifest and trust process |
